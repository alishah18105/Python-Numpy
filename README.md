# Python NumPy

A hands-on repository documenting my journey of learning **NumPy for Python-based data analysis and numerical computing**.

This repository covers NumPy concepts progressively, starting from the fundamentals and moving toward array manipulation, vectorization, broadcasting, handling missing values, and practical data-cleaning exercises.

---

## 📚 Topics Covered

The repository is organized into the following modules:

### 1. Introduction

* Introduction to NumPy
* Installing and importing NumPy
* Understanding the role of NumPy in Python

### 2. NumPy Basics

* Creating NumPy arrays
* Array dimensions
* Array properties
* Data types
* Basic mathematical operations
* Array functions

### 3. Indexing & Slicing

* Accessing array elements
* Positive and negative indexing
* Slicing one-dimensional arrays
* Slicing multi-dimensional arrays
* Selecting specific rows and columns

### 4. Reshaping & Manipulating

* Reshaping arrays
* Flattening arrays
* Combining arrays
* Splitting arrays
* Adding and removing elements
* Array manipulation techniques

### 5. Array Modification

* Updating array elements
* Conditional modification
* Adding and deleting values
* Working with copies and views

### 6. Vectorization

* Understanding vectorized operations
* Performing calculations without explicit loops
* Improving the efficiency of numerical operations

### 7. Broadcasting

* Understanding NumPy broadcasting
* Broadcasting rules
* Performing operations between arrays of different shapes
* Practical broadcasting examples

### 8. Handling Missing Values

* Identifying missing values
* Working with `NaN`
* Handling infinite values
* Replacing missing values
* Basic data-cleaning techniques

### 9. Project

A practical project that brings together the concepts learned throughout the repository.

The project focuses on working with real-world-style data and applying NumPy & Pandas techniques for data cleaning and preparation.
